# FreelanceFlow

A comprehensive freelance management system to streamline your workflow.

## Project Structure

- `backend/`: Node.js/Express server with MySQL
- `frontend/`: React application with Vite and Tailwind CSS

## Getting Started

### Backend

1. Navigate to `backend/`
2. Install dependencies: `npm install`
3. Configure `.env` file with your database credentials
4. Start the server: `npm run dev`

### Frontend

1. Navigate to `frontend/`
2. Install dependencies: `npm install`
3. Start the development server: `npm run dev`

## Features

- Client Management
- Project Tracking
- Task Management
- Time Tracking
- Invoicing
- Dashboard Analytics
